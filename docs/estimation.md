# 状态估计：传感器、EKF 与闭环精度

控制器如果直接吃仿真真值，数字再漂亮也只是自洽。这一层把真值换成传感器量测，用 15 维误差状态 EKF 还原姿态、位置、速度和两类零偏，再让控制器只用估计值闭环。

对应代码：`+uav/+sens/`、`+uav/+est/`、`+uav/+sim/run_est.m`、`tests/tEstimation.m`。

## 传感器模型

| 传感器 | 频率 | 噪声 | 零偏 | 备注 |
| --- | --- | --- | --- | --- |
| IMU 陀螺 | 200 Hz | 0.004 rad/s | 常值，默认 [0.02, −0.015, 0.01] rad/s | 零偏量级参照消费级 MEMS |
| IMU 加计 | 200 Hz | 0.08 m/s² | 常值，默认 [0.10, −0.08, 0.06] m/s² | |
| GPS 位置 | 5 Hz | 水平 1 m、垂直 2 m | 无 | 可配置丢星区间 |
| GPS 地速 | 5 Hz | 0.15 m/s | 无 | 真实接收机常规输出 |
| 气压计 | 20 Hz | 0.15 m | 无 | 只测高度 |
| 磁力计 | 50 Hz | 0.03（可降到 0.015） | 无 | 三轴向量，参考场 [0.42, 0, 0.91] |
| 下视光流 | 50 Hz | 0.03 m/s | 2% 标度误差 | 输出机体系水平速度 |

## EKF 结构

误差状态 15 维，顺序 `[δp; δv; δθ; δbg; δba]`，姿态用四元数单独维护（body→NED）：

- 预测：四元数用 `gyro − bg` 积分，速度用 `R·(f − ba) + g` 积分，协方差 `P = F P F' + Q`。
- 雅可比：`F(1:3,4:6)=I`、`F(4:6,7:9)=−R[f]×`、`F(4:6,13:15)=−R`、`F(7:9,10:12)=−I`、`F(10:12,13:15)=−I`。
- 修正：Joseph 形式更新，姿态误差按 `q ← q ⊗ [1; δθ/2]` 注入后归一化。
- 量测：
  - GPS 位置 `H = [I 0]`。
  - GPS 速度 `H = [0 I]`。
  - 气压计 `H = −1` 于 `pd`。
  - 磁力计三轴向量，`H = skew(mPred)`，`mPred = R'·mRef`。
  - 光流，机体系两轴，`H = R(1:2,:)` 作用在速度误差上。
  - 加计姿态，`H = skew(fPred)`，带两道门：`|‖f‖ − g| < 0.3 m/s²` 且 `‖gyro − bg‖ < 0.3 rad/s`。

## 三个必须踩过才知道的点

1. **控制周期必须 ≥ 500 Hz。** 带估计器的反馈里，5–10 ms 的滞后就足以让姿态环失稳：100 Hz 下即使传感器完美，姿态也振荡到 30°；1 kHz 下同样的增益稳定到毫米级。这不是估计精度问题，是相位。
2. **加速度计姿态更新会毁掉机动段。** 原始实现 200 Hz、门限 1 m/s²，机动时把推力方向当重力方向，闭环直接发散 188 m。降到 50 Hz、门限 0.3 m/s² 并加速度门控之后，姿态偏差从 3.3° 降到 1.5°。
3. **GPS 地速比位置差分可靠得多。** 只给位置时，速度估计有约 0.5 m/s 的常值偏差，被位置环 `Kd=2.2` 放大成 12° 左右的倾角指令，机体缓慢绕圈。加上 0.15 m/s 的地速量测后，速度误差均值从 0.53 m/s 降到 0.01 m/s，悬停误差从 0.87 m 降到 0.20 m。

## 精度（60 s 悬停，默认噪声）

| 项目 | 数值 |
| --- | --- |
| 位置 RMS（30 s 后） | 0.079 m |
| 位置最大偏差 | 0.130 m |
| 末端误差 | 0.078 m |
| 最大倾角 | 6.0° |
| 陀螺零偏估计 | [0.0199, −0.0149, 0.0099] rad/s（真值 [0.020, −0.015, 0.010]） |
| GPS 丢星 30 s（靠光流） | 末端漂移 0.09 m，最大 0.15 m |
| 理想传感器闭环 | 末端 5.2 cm、RMS 5.5 cm |

原本定的 5 cm 闭环目标没有达到。把光流噪声压到 0.02 m/s 也只能到 6.5 cm，继续降增益只让倾角变小、误差反而不降——剩下的是传感器噪声经过位置环的必然抖动，不是调参能消掉的。要再往下压，得上 RTK 或外部动捕。

## 复现

```matlab
p = uav.cfg.quad(); c = uav.cfg.ctrl();
s = struct('dt',1e-3,'ctrlDiv',1,'tEnd',60,'logDiv',10);
out = uav.sim.run_est(p, c, s);        % 默认含光流
```

`run_est` 的 `s.sens` 字段可以关掉任意一路（`useFlow`、`useMag`、`useAccel`、`usePos`），或改噪声与零偏；`gpsDrop = [t1, t2]` 模拟丢星。`useTruth`、`useTruthPV`、`rawRate`、`estLp` 是调试开关，用于隔离「反馈里哪一路坏了」，默认关闭。

## 测试

`runtests('tests/tEstimation.m')` 共 8 项：零偏收敛、丢星漂移、理想传感器精度、光流增益对比、估计无偏、悬停亚分米、姿态估计误差、重复运行逐位一致。
