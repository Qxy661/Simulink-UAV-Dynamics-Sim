# 倾转四旋翼（tilt-rotor）

四个旋翼装在机翼上，短舱绕机体 y 轴转。β=0 推力朝上，β=90° 推力朝前。
悬停靠旋翼，巡航靠机翼，中间靠调度把控制权限从旋翼交给舵面。

这是一段**过渡段**的模型，不是完整 eVTOL。稳定走廊到 β=57°、空速 10 m/s。

## 机体与旋翼

| 量 | 值 |
| --- | --- |
| 质量 | 8.0 kg |
| 惯量 | diag(0.90, 1.20, 1.60) kg·m² |
| 机翼 | S 1.60 m²，b 3.60 m，c 0.34 m |
| 旋翼位置 | x=±0.40 m，y=±0.90 m |
| 推力系数 | kt 2.6e-5 N/(rad/s)² |
| 反扭矩系数 | kd 5.0e-7 N·m/(rad/s)² |
| 转速上限 | 1100 rad/s |
| 悬停转速 | 868.7 rad/s |
| 短舱 | τ 0.15 s，速率 30°/s，0..90° |
| 气动 | CL0 0.45，CLa 5.0，CD0 0.025，kind 0.045 |
| 舵面 | de ±25°，da ±20°，dr ±25° |

状态 21 维：13 维刚体（与四旋翼一致）+ β + 4 个转速 + 3 个舵面，RK4 @1 ms。

## 推力与力矩

推力方向（机体系，z 向下）：

```
d(β) = [sinβ; 0; -cosβ]
```

虚拟控制量：

```
U1 = Σ Ti          U2 = -Σ yi·Ti
U3 = Σ xi·Ti       U4 = Σ si·Ti
```

旋翼力偶：

```
Mx = cosβ·U2 - kq·sinβ·U4
My = cosβ·U3
Mz = sinβ·U2 + kq·cosβ·U4
```

β=0 时退化为四旋翼：滚转、俯仰来自转速差动，偏航来自反扭矩差动。
β=90° 时推力全朝前，转速差动不再产生滚转力矩，只剩 kq·U4 的偏航，
滚转权限必须交给副翼。这就是"权限混合"的物理来源，不是控制器偏好。

逆混控（aY=0.90，aX=0.40）：

```
T1 = U1/4 - U2/(4aY) + U3/(4aX) + U4/4
T2 = U1/4 - U2/(4aY) - U3/(4aX) - U4/4
T3 = U1/4 + U2/(4aY) - U3/(4aX) + U4/4
T4 = U1/4 + U2/(4aY) + U3/(4aX) - U4/4
```

反解（控制器用）：

```
U2 = cosβ·Mx + sinβ·Mz
U3 = My / cosβ
U4 = (-sinβ·Mx + cosβ·Mz) / kq
```

## 控制器

调度量取**参考空速**，不用实测空速：

```
k    = clamp((ref.V - V1)/(V2 - V1), 0, 1)
beta = betaMin + (betaMax - betaMin)·k
```

用实测空速时，机体落后于计划 → k 回落 → 短舱收回 → 更落后，
过渡段来回摆。用参考空速是开环调度，短舱按任务计划单调前倾。

姿态指令按 k 线性混合两支：

- 四旋翼支：由推力需求 `Tn = m(a - g_n)` 构造期望机体系，反解 φ、θ。
- 固定翼支：`theta = alpha_trim + Kth_h·e_h - Kth_hd·hdot + KthV·e_V`，
  φ 由航向误差给。

推力大小也混合：

```
U1 = (1-k)·|Frot| + k·max(0, d'·Frot)
```

悬停时姿态会对齐推力方向，用模长；巡航时推力方向固定，用投影。
只用模长会把制动需求当成前向推力，β=90° 时速度一路涨到 85 m/s。

力矩分配：旋翼拿 (1-k)，舵面拿 k，舵面残余用线性导数反解，qbar 下限 1。
位置环带限速：实测速度超过参考 2 m/s 时，把沿速度方向的加速度压到负值。

关键增益（`+uav/+cfg/tiltctrl.m`）：

| 环 | 增益 |
| --- | --- |
| 位置 | Kp [1.0 1.0 1.6]，Kd [1.8 1.8 2.2]，Ki [0 0 0.8] |
| 加速度限幅 | 水平 2.5 m/s²，垂直 4.0 m/s² |
| 姿态 | Kp [6 6 3]，Kd [1 1 0.8]，Ki [0 0 0.6] |
| 力矩限幅 | [2.5 2.5 1.0] N·m |

## 包线

同一任务换个巡航速度重跑（V1=3、V2=14，40 s）：

| Vmax | 高度偏差 | 最大俯仰 | 最大 β | 结论 |
| --- | --- | --- | --- | --- |
| 8 m/s | 0.50 m | 6.6° | 40.9° | 稳定 |
| 10 m/s | 0.33 m | 7.8° | 57.3° | 稳定 |
| 12 m/s | 15.61 m | 8.8° | 73.6° | 掉高 |
| 14 m/s | 126.26 m | 75.4° | 90.0° | 发散 |
| 16 m/s | 118.07 m | 90.0° | 90.0° | 失稳 |

12 m/s 时 β=73.6°，旋翼竖直分量 cosβ=0.28，机翼升力
0.5·1.225·144·1.6·0.45 ≈ 63 N，小于重力 78.5 N。差的 15 N 只能靠旋翼，
而旋翼要同时提供前向推力，姿态和推力方向打架，于是掉高、抬头、失速。
这是配置的物理边界，调参解决不了；要扩走廊得加大机翼或提高 CLmax。

复现：`uav.env.tilt_ref_v(t, Vmax)` 是同一形状的参数化参考。

## Simulink 模型

`models/tilt_closed_loop.slx` 与另外两个构型同构：

```
Clock -> Ref -> Ctrl -> Deriv -> Int -+
                  ^                 |
                  +-----------------+
```

- `Ref`：纯函数图表，解析式任务参考，输出 12 维 `[p; v; a; psi; h; V]`。
- `Ctrl`：离散 1e-3，带 `persistent ip/ia`，输出 8 维 `[om; de; da; dr; beta]`。
- `Deriv`：纯函数，一次算完 21 维导数，含短舱、转速、舵面的一阶滞后。

参数在生成时写成字面量，模型不依赖 MATLAB 路径。生成与对拍：

```matlab
cd scripts
build_tilt_model
validate_tilt_model
```

45 s 对拍：最大偏差 6.65e-12，位置 0.000 mm，姿态 1.0e-14 rad，短舱逐位一致。
脚本侧 `ctrlDiv=1`，与模型里控制器 1 ms 采样对应。

## 未解决

1. **减速回悬停。** 从 10 m/s 减速到 0 时，姿态混合把倾角需求摊薄，
   实测位置滞后 25 m；β 收回 8° 后机体继续漂移，最终俯仰冲到 90° 失稳。
   当前任务在巡航结束就停止，不覆盖这一段。
2. **β=90° 全转换。** 包线到 57°，全转换需要更大的机翼或变距桨。
